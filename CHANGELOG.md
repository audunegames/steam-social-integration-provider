# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [0.2.0] - 2026-08-17

### Added

- Get relationships for the current user for Steam.
- Steam users now implement equality methods and can check if any game or the current game is being played.
- The Steam game overlay can now be activated from within the provider or a user.

## [0.1.0] - 2026-08-16

### Added

- A social provider component connecting the Steamworks SDK through Steamworks .NET to Audune Social Integration.
- Get the current user for Steam.
- Set rich presence to Steam.
- Handle activation of game overlays for Steam.
